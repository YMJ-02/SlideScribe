So let's kick things off with a quick overview of what deep learning actually is and why it's been so transformative over the last decade. At its core, a deep neural network is just a function — a very complicated, highly parameterized function — that maps inputs to outputs. What makes it deep is the fact that we stack many layers of transformations on top of each other, and each layer learns a slightly more abstract representation of the data than the one before it. The perceptron is the fundamental building block. A single perceptron computes a weighted sum of its inputs and passes it through an activation function. Stack thousands of these in parallel and you get a layer. Stack many layers and you get a deep network. Forward propagation is simply the process of passing the input through all of these layers from left to right, computing activations at each step. The backpropagation algorithm is how we actually train these networks: we compute the gradient of the loss with respect to every weight using the chain rule, then update the weights accordingly. One thing to be careful about is the vanishing gradient problem. When the network becomes deeper and the activation saturates, gradients can become too small for early layers to learn effectively.

Gradient Descent & Optimization

Loss Landscape
L(w) = (1/N) Σ (yᵢ − ŷᵢ)²
∂L/∂w = −(2/N) Σ xᵢ(yᵢ − ŷᵢ)
w ← w − α · ∂L/∂w
α = learning rate (0.001 ~ 0.01)

Transcript
Alright, so we've got our network architecture defined — now the question is how do we actually train it? That's where gradient descent comes in. The idea is simple: define a scalar loss function that measures how bad the current predictions are, and move the weights in the direction that makes the loss go down the fastest. For regression the standard choice is mean squared error. For classification you'd typically use cross-entropy instead. The gradient of the loss with respect to a particular weight tells us the slope of the loss surface in that direction, and moving opposite to the gradient is called steepest descent. The learning rate alpha is one of the most important hyperparameters you'll ever tune. If it's too large, updates overshoot the minimum and the loss can oscillate or diverge. If it's too small, training becomes painfully slow. In practice, people often use Adam because it adapts the effective learning rate for each parameter based on the first and second moments of the gradient. If you look at a typical loss curve, you'll see a sharp drop at the beginning, followed by a slower taper as the network approaches a good region of the parameter space.

Transcript
Convolutional Neural Networks were the breakthrough that really pushed deep learning into the mainstream for image-related tasks. The key insight is that natural images have strong local structure — nearby pixels are highly correlated, and similar patterns such as edges, corners, and textures appear in many locations. A convolutional layer applies a small learned filter, for example a 3×3 kernel, across the image. At every spatial location the filter computes a dot product with a local patch, producing a feature map. This gives us parameter sharing and translation equivariance almost for free. Pooling layers then reduce the spatial resolution while preserving the strongest activations. Max pooling is the standard choice because it keeps the most salient response in each window. After several rounds of convolution and pooling, the feature maps are flattened into a one-dimensional vector and sent into dense layers to produce class scores. Finally, a softmax layer converts those scores into a probability distribution over all target classes, allowing the model to output a clear prediction.
