So let's kick things off with a quick overview of what deep learning actually is and why it's been so transformative over the last decade. At its core, a deep neural network is just a function — a very complicated, highly parameterized function — that maps inputs to outputs. What makes it deep is the fact that we stack many layers of transformations on top of each other, and each layer learns a slightly more abstract representation of the data than the one before it. The perceptron, which you've probably seen before, is the building block. A single perceptron computes a weighted sum of its inputs and passes it through an activation function. Stack thousands of these in parallel and you get a layer. Stack many layers and you get a deep network. Forward propagation is just the process of passing your input through all those layers from left to right — from input to output — computing activations at each step. We'll formalize that in a moment. The backpropagation algorithm is how we actually train these networks.

Alright, so we've got our network architecture defined — now the question is how do we actually train it? That's where gradient descent comes in. The idea is beautifully simple: we define a scalar loss function that measures how bad our current predictions are, and we move the weights in the direction that makes the loss go down the fastest. For regression the standard choice is mean squared error — you square the difference between the prediction and the ground truth and average over all your training examples. For classification you'd typically use cross-entropy loss instead. The gradient of the loss with respect to any weight tells us the slope of the loss landscape in that direction. Moving opposite to the gradient is called steepest descent. The learning rate alpha is genuinely one of the most important hyperparameters you'll tune. Set it too high and your updates will overshoot the minimum and the loss will actually go up or oscillate wildly.

Convolutional Neural Networks were the breakthrough that really put deep learning on the map, specifically for image-related tasks. The key insight is that natural images have a strong spatial structure — nearby pixels are related, and the same features like edges and textures appear in many different locations. A fully connected layer has no way to exploit this structure because it treats every pixel independently regardless of position. A convolutional layer instead applies a small learned filter — say 3×3 pixels — at every possible position in the image, computing a dot product between the filter weights and the local image patch. This gives us two huge advantages. First, parameter sharing: the same filter is reused everywhere. Second, translation equivariance: if the cat moves two pixels to the right, the feature map just shifts two pixels to the right.
